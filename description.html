Tiny AI Prompt Generator: Teaching Prompts from the Editor

A button in the TinyMCE editor opens a guided builder for teaching prompts. It uses the data of the course and sends the prompt to the AI provider of your choice, with the answer streamed back inside Moodle.

What's New in v2.0.0

  • Security release: the streaming endpoint accepts only requests with a valid session key, links in AI responses are checked, the Gemini API key is no longer sent in the URL, Moodle's curl security applies to the cloud providers, and the rate limit is counted per user.
  • Streaming for every provider: OpenAI responses stream too, and one AI client builds every request with the same model, system prompt and limits.
  • Current AI models: new defaults for OpenAI, Gemini and Claude, and correct handling of models that reason before they answer.
  • Fixes: Ollama and custom endpoints on the local network, Gemini responses with code, and API errors shown as errors.

Core features

  • Guided builder: subject, topic, lesson, student age, class type, audience, language and learning outcomes; the prompt updates as you choose.
  • Course-aware: Browse dialogs insert the sections and activities of the course, learning plan competencies and gradebook outcomes.
  • Several AI providers: OpenAI, Google Gemini, Anthropic Claude, DeepSeek, any OpenAI-compatible API (LM Studio, Groq, OpenRouter, vLLM) and Ollama for local models on your own server.
  • Streaming answers: the response appears while it is generated.
  • Quick templates: ready-made teaching prompts, and administrators add their own JSON templates with placeholders such as {subject}, {topic} and {outcomes}.
  • Response views: raw output, plain text, rendered HTML or HTML code, each ready to copy.
  • Administrator controls: system prompt, temperature, maximum length and a rate limit of requests per user and hour; the toolbar tooltip names the active provider and model.

The AI prompt plugins

  • Tiny AI Prompt Generator (this plugin): the prompt builder as a button in the TinyMCE editor.
  • AI tools for teachers - prompt generator: the same builder as a course block.

Requirements

  • Moodle: 4.1 to 5.3 with the TinyMCE editor, PHP 8.1 or newer.
  • An AI provider: an API key of OpenAI, Gemini, Claude, DeepSeek or an OpenAI-compatible service, or an Ollama server. Set it in Site administration, Plugins, Text editors, TinyMCE editor, AI Prompt Generator.

Privacy

The plugin stores no personal data in Moodle. When a teacher sends a prompt, the prompt is sent to the AI provider the administrator set up (an outside service, or your own Ollama server). The external services are declared in the Moodle Privacy API.
